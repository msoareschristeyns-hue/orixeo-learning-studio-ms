# Orixeo Activity Library

Bibliotheque pedagogique professionnelle autonome de MSDG Innovation / Orixeo Lab.

## Vision

Transformer une bibliotheque de fiches en outil de production de formations : rechercher une activite, l'adapter au public, afficher la fiche apprenant et le corrige formateur, puis l'integrer a Orixeo Learning Studio.

## V1

- recherche plein texte
- filtres par domaine, format et niveau
- fiches activites structurees
- vue apprenant
- vue formateur avec reponses attendues et debrief
- catalogue initial Achats, Supply Chain, RSE, IA, anticipation strategique et transmission
- architecture independante et connectable a Orixeo Learning Studio
